
# AI-Powered Retail Financial Risk & Intelligence Platform

## Project Overview

This project explores how machine learning can be used to identify unusual retail financial behaviour, predict transaction cancellations, segment customers and forecast sales.

## Business Context

The project is designed around the challenges faced by large European retailers, with Lidl/Schwarz Group used as the business context.

## Objectives

- Detect unusual transactions
- Predict transaction cancellations
- Segment customers
- Forecast sales
- Incorporate external economic and environmental data
- Provide actionable business recommendations

## Data

The project uses real-world publicly available datasets.

### Core Dataset

UCI Online Retail II

Source:
https://archive.ics.uci.edu/dataset/502/online%2Bretail

Additional data sources will include Eurostat, weather and public holiday data.
